# Wordflow v0.7 branch: what changed

Record of the work on branch `v0.7` of ldaca-wordflow from 24 September to 7 October 2026 (`aaea1c3b..a6ca90d4`, 354 commits), written for the team before v0.8. For a porting checklist with full detail, see [v0.7-to-v0.8-migration-instructions.md](v0.7-to-v0.8-migration-instructions.md).

Branch `v0.7` was cut from `main` at aaea1c3b on 24 September 2026 for v0.7.x fixes and interface changes, while v0.8 (DuckDB, new UI) is built separately. Most of the work came from Chao's testing in Safari, from ANU tester feedback, and from a wording audit of the whole app (#205).

The changes fall into four groups. New data tools: the Data Editor gained in-place column tools with a live preview, and the Data Builder gained Segment, Group, Aggregate and Deduplicate. Analysis fixes and features: keyness direction, per-million counts, Topic Modelling colour-by, segmentation and Max topic size, and a Concordance dispersion alignment fix. A plain-language pass: every error, label and help page. Shared behaviour: tables keep their scroll, renames recover from failures, tabs are named F-1, C-1 and so on, and errors keep their technical text under Details.

Everything below was checked by Chao in the app or in Playwright WebKit on an isolated instance, and the relevant issues were closed or are waiting for confirmation. Frontend tests: 1,666 passing. Backend tests: 1,171 passing, plus one known failure (`test_server_launcher`, which needs a built frontend).

## Rules that now apply everywhere

- **Errors (R1).** Errors are written sentences starting "Couldn't …". Technical text (exceptions, Polars messages) is shown only under **Details**, with Copy details and Send feedback.
- **Tables (R2).** Sorting, paging or updating a table never moves the page. Tables render cells without `flexRender`, keep the old rows (dimmed) while loading, and hold their height through an update.
- **Renames (R3).** One rule for every rename box. A failed rename keeps the box open with the text selected; clicking away without changing it keeps the original name; Enter retries and Esc cancels.
- **Tab names (R4).** New analysis tabs are F-1, C-1, T-1, TM-1, Q-1 or A-1. Older numbered tabs show with the prefix, and the Tasks panel uses the same names.
- **Wording (R5).** Always "Data Block" and "Project". Australian spelling, sentence case, "…", "Select all" / "Select none", "column" (not field), "README", and Import (into Wordflow) vs Download (to the computer). One vocabulary for data types; dates are shown year first.
- **Safari (R6).** Every scroll, focus and layout change is checked in Playwright WebKit.
- **Help (R7).** The help pages are written in `frontend/public` and published to the `ldaca-wordflow-docs` mirror under the tag `v0.7`. One plain section explains Preview, Run and Clear.
