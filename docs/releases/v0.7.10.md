Wordflow 0.7.10 makes uploads visible and dependable, lets Concordance and Quotation run again on their own results, and fixes problems found while stress testing the hosted server.

## Files

- **Uploads in the Tasks panel**: each upload shows as a task, for example "L - Upload: data.zip", with how much has been sent, the speed and the time left (and which file, for several). It keeps going while you work in other views. **Stop** ends it at once; a file only partly sent is not kept. When it finishes, its arrow opens the folder in the Data Loader.
- **Large uploads finish**: uploads no longer stop after 30 seconds, which made large files fail on slower connections. An upload that makes no progress for a minute stops and says so; some networks, such as campus networks, hold large uploads.
- **Your files stay usable during an upload**: the file list no longer waits for an upload to finish.
- **No fixed upload limit**: on a shared Wordflow server, uploads count toward your storage space instead of a 512 MB limit per file. Before an upload over 50 MB there, Wordflow reminds you that the server is for trying Wordflow out and is shared, and suggests the desktop app for large corpora; choose **Upload anyway** to continue.
- Reloading or closing the page while an upload runs now asks first.
- A folder that is receiving an upload cannot be deleted or moved until the upload finishes or is stopped. On Windows this failed part way with a server error. Deleting a single file or folder now says why when it fails.

## Analysis tools

- **Concordance and Quotation on their own results**: searching a Data Block made from a Concordance or Quotation Result works, including when the text you search is itself a column the tool adds, such as stacked `CONC_extraction` text. The Result keeps that text as `CONC_source` or `QUOTE_source`, the tool's columns are replaced by one fresh set, and Add to Project no longer offers the old ones. Quotation's Add to Project also works when the source already has a column such as `speaker`.
- **Topic Modelling**: Add to Project works on a Data Block made from a Topic Modelling Result; a `TOPIC_` column chosen as the text is refused with a plain explanation.
- **Trends and Concordance density**: tooltips show each series' colour, and stacks follow the legend order from the top.

## Everywhere

- **LDaCA collections**: **Update access token** opens Settings at the Portal tab.
- **Sidebar**: the Views list starts at the height of its entries and follows them when you show or hide a view, until you drag its edge; a dragged height stays until the next start.
- **Windows**: Help > Check for Updates opens the update window again.
- **References**: the version line names the exact commit, linked on GitHub, for testers and developers. The suggested citation now credits the Sydney Informatics Hub and gives Wordflow's Zenodo DOI, which always leads to the latest version, and Help calls the app simply Wordflow.
- **Light theme, higher contrast**: secondary text, borders, placeholders, Project Graph edges and chart lines are darker and easier to read, and pure white is slightly softened. The dark theme and the data colours (series, Data Blocks) are unchanged.
- **Help window**: the header shows the LDaCA, ARDC, NCRIS, Sydney Corpus Lab and Sydney Informatics Hub logos, each linking to its website, beside the page title (Help, Information or References), and every Help page opens with the same style of title.
- **Help**: every **?** shows a short reminder on hover and opens its Help section on click. This works again beside Segments, Max tokens, Topic size, Seed and Per document in Topic Modelling, and Trends' **Spacing** and legend now use **?** instead of an **i** that only showed a tooltip; their Help sections explain which spacing to choose and how to read a legend entry. Help opens at the right section even while its pictures are still loading. The Help header stays at the top while you scroll; Help text is readable in the dark theme; screenshots are toned so faint lines show, and dimmed in the dark theme; and Help no longer calls its pages tutorials.

## Hosted servers

- Stopping or restarting the server no longer waits 90 seconds for open browser tabs.
- One user's refused request can no longer close another user's open Project.
- WebSocket requests from internet scanners are refused cleanly instead of causing server errors.
- A dropped upload is reported as interrupted, not as a server error.
- Servers upgrading from 0.7.6 can move their user database and Projects with `backend/scripts/migrate_076_server_data.py`.
- The hosted runbook's systemd unit now uses `KillMode=mixed` and `TimeoutStopSec=30`, so a restart marks running analyses as interrupted. Existing servers should add the same two settings.

## Upgrading

Servers that relied on the 512 MB upload limit can keep one with `MAX_FILE_UPLOAD_BYTES`.
