Wordflow 0.7.10 makes uploads visible and dependable, lets Concordance and Quotation run again on their own results, and fixes problems found while stress testing the hosted server.

## Files

- **Uploads in the Tasks panel**: each upload shows as a task, for example "L - Upload: data.zip", with how much has been sent, the speed and the time left (and which file, for several). It keeps going while you work in other views. **Stop** ends it at once; a file only partly sent is not kept. When it finishes, its arrow opens the folder in the Data Loader.
- **Large uploads finish**: uploads no longer stop after 30 seconds, which made large files fail on slower connections. An upload that makes no progress for a minute stops and says so; some networks, such as campus networks, hold large uploads.
- **Your files stay usable during an upload**: the file list no longer waits for an upload to finish.
- **Import history**: importing the same collection twice into one folder could leave "User File Import history is corrupt" in Tasks after every restart; it now clears itself at the next start.
- **No fixed upload limit**: on a shared Wordflow server, uploads count toward your storage space instead of a 512 MB limit per file. Before an upload over 50 MB there, Wordflow reminds you that the server is for trying Wordflow out and is shared, and suggests the desktop app for large corpora; choose **Upload anyway** to continue.
- Reloading or closing the page while an upload runs now asks first.
- A folder that is receiving an upload cannot be deleted or moved until the upload finishes or is stopped. On Windows this failed part way with a server error. Deleting a single file or folder now says why when it fails.

## Analysis tools

- **Concordance and Quotation on their own results**: searching a Data Block made from a Concordance or Quotation Result works, including when the text you search is itself a column the tool adds, such as stacked `CONC_extraction` text. The Result keeps that text as `CONC_source` or `QUOTE_source`, the tool's columns are replaced by one fresh set, and Add to Project no longer offers the old ones. Quotation's Review table and Add to Project also work when the source already has a column such as `speaker`.
- **Topic Modelling sizes**: each size chip shows the count and that count's share of its group, for example *296 · 7.9%*, in the hover card, the topic list and the HTML download. Hover over a chip for both numbers. Help explains why the percentages in one topic do not add up to 100%.
- **Topic Modelling topic count**: the Topics slider stays selected after each update, and the arrow keys apply after a short pause, so several presses make one update.
- **Topic Modelling**: Add to Project works on a Data Block made from a Topic Modelling Result; a `TOPIC_` column chosen as the text is refused with a plain explanation. The Topic Map no longer reports "the source Data Block no longer has the rows" for a Data Block with only a text column.
- **Trends and Concordance density**: tooltips show each series' colour, and stacks follow the legend order from the top.
- **Concordance sorting**: with **Case sensitive** off, sorting by matched text, L1 or R1 treats *The* and *the* as one word, and the L1/R1 counts do too. Rows with the same value stay in Data Block order (by document, then position), and rows are shaded in bands by document.
- **What you see is what you get**: **Add to Project** from a sorted Concordance or Quotation table keeps the table's order, and the Keyword Analysis CSV keeps its sort while the token filter is on. **Original order** returns a sorted Concordance or Quotation table to the Data Block order. Sorting the Concordance table no longer upsets Dispersion view.
- **Concordance Tokens mode**: always ignores capitals (tokens are lowercased), so Case sensitive and Ignore punctuation are now Text-mode options only. L1 and R1 are marked in the context even when the word there has capitals.
- **Trends and Concordance density**: the range slider under the chart shows the total of the visible groups and lines up with the chart, including gaps in **To scale** spacing.
- **Quotation**: the Built-in / Remote engine choice is gone; Remote needed a service no public Wordflow has.
- **Review tables** only offer the sorts that Add to Project can keep, so sorting by a list column is no longer offered.

## Charts

- **Interactive HTML download**: Trends and Concordance density charts can be saved as one web page that opens offline and shows the chart exactly as on screen, with tooltips, a legend that hides and shows groups, and zoom. The Topic Modelling bubble chart can be saved the same way, with **Find topics** to highlight topics, hover cards with each topic's words sized by frequency, and pan and zoom.
- **Trends chart downloads** list the chart's settings in plain words (Data Block, Time column, Period, Groups and Values), and long headers wrap instead of overlapping.
- **Interactive HTML downloads** zoom only while you hold Command (Mac) or Control (Windows) and scroll; plain scrolling scrolls the page, or moves a zoomed-in bubble chart. The file keeps the period you had selected in Trends, lists stacked groups in the chart's order, drops a hidden group from the tooltip, and links Wordflow in its footer to the Wordflow home page.
- **Topic search**: `*` and `?` now match within a single word, so `gs*` and `gs?` find topics with *gst* anywhere in their word list.
- **Two Data Blocks, named**: Topic Modelling shows a Bubble colour legend naming each Data Block and the blend between them, and the Juxtorpus scale names Reference and Study; downloads of both carry these legends. Legends in chart downloads no longer overlap long names.
- **Concordance Combined view**: the density chart says it combines both Data Blocks and points to Separated view for one chart each.

## Data Builder

- **Filter**: number columns can use **between**, with From and To (both included; leave one empty for an open range). Text that is not a number is refused in plain words, and changing the operator clears the range.
- **Sample and Shuffle** with no random seed now draw one when the Data Block is created and record it, so the Data Block keeps its rows across pages, analyses and restarts.
- **Stack**: changing one column to a category no longer makes other category columns show as different types.

## Data Editor

- **Combine columns** can add a column with one fixed value: a template with no column, such as `Hansard`, puts that text in every row.
- An edit that cannot run, such as Find & replace with an invalid regular expression, is refused with a plain message instead of being applied; **Apply** waits for a good preview. Segment refuses an invalid pattern the same way.
- **Replace** and **Extract** use the new column name as typed and never overwrite another column.
- **Row Details** no longer lists Wordflow's internal columns.

## Everywhere

- **LDaCA collections**: **Update access token** opens Settings at the Portal tab.
- **Sidebar**: the Views list starts at the height of its entries and follows them when you show or hide a view, until you drag its edge; a dragged height stays until the next start.
- **Desktop app Help**: the desktop app now loads the published Help pages, so later Help corrections reach it without an app update, as they already did for web versions. Earlier desktop versions keep their built-in Help until updated.
- **Windows**: Help > Check for Updates opens the update window again.
- **Starting**: while Wordflow connects to its server at start the screen says so, instead of advising a restart; the first start on a new computer can take a few minutes.
- **Tabs**: resizing the window no longer scrolls the tab strip back to the active tab. A task whose tab was just deleted is named by its tool and opens nothing.
- **References**: the version line names the exact commit, linked on GitHub, for testers and developers. The suggested citation now credits the Sydney Informatics Hub and gives Wordflow's Zenodo DOI, which always leads to the latest version, and Help calls the app simply Wordflow.
- **Light theme, higher contrast**: secondary text, borders, placeholders, Project Graph edges and chart lines are darker and easier to read, and pure white is slightly softened. The dark theme and the data colours (series, Data Blocks) are unchanged.
- **Help window**: the header shows the LDaCA, ARDC, NCRIS, Sydney Corpus Lab and Sydney Informatics Hub logos, each linking to its website, beside the page title (Help, Information or References), and every Help page opens with the same style of title.
- **Help**: every **?** shows a short reminder on hover and opens its Help section on click. This works again beside Segments, Max tokens, Topic size, Seed and Per document in Topic Modelling, and Trends' **Spacing** and legend now use **?** instead of an **i** that only showed a tooltip; their Help sections explain which spacing to choose and how to read a legend entry. Help opens at the right section even while its pictures are still loading. The Help header stays at the top while you scroll; Help text is readable in the dark theme; screenshots are toned so faint lines show, and dimmed in the dark theme; and Help no longer calls its pages tutorials.

## Hosted servers

- Stopping or restarting the server no longer waits 90 seconds for open browser tabs.
- One user's refused request can no longer close another user's open Project.
- WebSocket requests from internet scanners are refused cleanly instead of causing server errors.
- A dropped upload is reported as interrupted, not as a server error.
- Servers upgrading from 0.7.6 can move their user database and Projects with `backend/scripts/migrate_076_server_data.py`.
- The hosted runbook's systemd unit now uses `KillMode=mixed` and `TimeoutStopSec=30`, so a restart marks running analyses as interrupted. Existing servers should add the same two settings.

## Upgrading

Servers that relied on the 512 MB upload limit can keep one with `MAX_FILE_UPLOAD_BYTES`.
