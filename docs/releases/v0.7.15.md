Wordflow 0.7.15 makes AI annotation more reliable, lets Projects of any size be imported and exported, and fixes downloads in the desktop app. The 0.7.14 notes follow, for anyone updating from an earlier version.

## Fixed in 0.7.15

- **Large Projects import and export**: importing a Project could fail with "Project manifest exceeds the configured limit" once it held a number of saved Analyses, and Projects over about 500 MB could not be imported or over 2 GB exported. Projects now import and export at any size; only free disk space (and, on a shared server, your storage quota) limits them. Importing also no longer needs over 10 GB of free disk for a small Project.
- **Add to Project without the document column works**: in Concordance and Quotation, **Add to Project** with the document column unticked showed a success message but added nothing. It now adds the Data Block, and if adding a Data Block ever fails, Wordflow says so instead of only showing it in **Tasks**.
- **Files keep their file type in the desktop app**: renaming a file in the Save window no longer drops its `.csv`, `.xlsx` or `.zip` ending, so Windows and Excel recognise it.
- **Clear messages when a desktop download fails**: the desktop app shows the reason, as a browser does, instead of an internal code such as `backend_download_http_400`.
- **Excel's cell limit explained**: when text is too long for an Excel cell (32,767 characters), Wordflow names the column, suggests what to do beside **Format**, and links to a new help section. That section explains that Excel also breaks a CSV with such text, and which programs open it correctly (LibreOffice Calc, Numbers).
- **The update window stays in view on Windows**: when the check at start finds a new version, the update window no longer hides behind the main window.
- **Annotation runs no longer stall for 5 minutes now and then on hosted LLM gateways**: each request to an AI provider now closes its connection when it ends. Before, about 1 in 80 requests could get no answer and wait for the full 5-minute timeout before it was tried again. A connection that can't be opened now fails after 15 seconds.
- **Annotation no longer splits batches when a model wraps its answer in a code block**: some models put their answer in a Markdown code block, or give one label too few, and Wordflow then split the batch again and again, sometimes down to one row per request (one run needed 6 times as many requests). Wordflow now reads an answer inside a code block, and asks Custom providers that support it to return exactly one label per row. Answers with the wrong number of labels or an unknown code are still refused.

## Changed in 0.7.15

- **Task context in the codebook**: the Edit codebook window has an optional **Task context** that says what the texts are and what the codes are for. It is saved with the codebook and sent to the AI with every request, after the prompt. Projects that don't use it still open in 0.7.14.
- **Model descriptions in the Annotation model list**: when a provider describes its models (OpenRouter, Google, or a LiteLLM gateway with descriptions set), each model in the **Model** list has a one-line description under its name.
- **No "(recommended)" after the document column** in the Add to Project and download windows. The document column still starts ticked.
- **Wider columns in the Data Loader preview**: drag a column header's edge to widen it and read more; long texts no longer show as blank on a Mac.
- **Sign-in with other OIDC providers (hosted servers)**: a server can now sign in through providers such as a Keycloak realm, with the new `CILOGON_SCOPES` setting and an issuer that includes a path. Existing servers are unchanged.
- **"Sign in with SSO" on hosted servers**: the sign-in button no longer names CILogon, since the same sign-in can be CILogon (AAF) or another single sign-on provider. It reads **Sign in with SSO** and takes you to whichever one the server uses.

## What came in 0.7.14

- **Works on university networks that check secure connections**: some university and company networks (for example with Zscaler) inspect secure connections. On a Mac or Windows computer on such a network, Wordflow couldn't reach anything online: importing LDaCA collections stopped with "Data Portal collections could not be listed", and sample data, AI annotation and checking for updates failed too. Wordflow now trusts the same certificates as your computer, so they work wherever your browser does.
- **Looks for a new version at every start and every day**: the desktop app now checks each time it starts, and once a day while it stays open, instead of at most once a day at start; after **Decide later** it offers the new version again the next day. Turn the checks off under **Settings → General**. On Binder, a pip install or a shared server, a short notice now says when a newer Wordflow is out and how to get it; on a shared server, it suggests asking for an upgrade with **Feedback**, or using the desktop app or Binder.
- **Downloads from several Data Blocks in the desktop app**: downloading Concordance or Quotation results from two or more Data Blocks saved a ZIP under the first Data Block's CSV name, so it looked as though only the first table was saved. It is now saved as a ZIP with one table per Data Block, as on a server.
- **Dates of files in a downloaded ZIP**: the tables inside a downloaded ZIP were dated 1 January 1980; they now carry the time of the download.
- **Codebook check**: Annotation's Codebook now warns when a code is listed more than once or two codes share a description, and suggests a fix: remove the repeated rows, choose one of a code's descriptions or merge them, or give each code its own description. AI **Preview** and **Run** wait until each code has one description, instead of quietly using the first. The Edit codebook picture in the help now shows each code once.
- **Collapsing the Project panel on a phone**: on a narrow screen, such as a phone held upright, the Project panel sits below the analysis. Collapsing it now leaves a slim bar at the bottom and gives the analysis the whole screen, instead of leaving the bottom of the page blank.
