## New in 0.7.18

- **The end of Topic Modelling is quick and light on large corpora**: the last step ("finding each topic's words") could spend many seconds on one processor and several gigabytes of memory preparing the results of a large corpus. It now takes a fraction of a second and a fraction of the memory. The topics and their sizes are unchanged.
- **The same topics every time**: running Topic Modelling again on the same text with the same settings and seed now gives exactly the same topics, on any computer or server. Before, a computer with several processors could give a slightly different set of topics on each run of a corpus with more than about 8,000 segments. Because of this fix, a run made with 0.7.18 can differ a little from the same run made with an earlier version.
- **The Search term example is lighter**: "e.g. house, pre, gov" in the Topic Modelling search box is now grey, like other examples, so it doesn't look like typed text.
