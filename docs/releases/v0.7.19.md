Wordflow 0.7.19 fixes downloading a Project that has an unrun Concordance, Quotation or Annotator preview, highlights new files, folders and Projects after an upload or import, and calls Topic Modelling's stretches of text passages. The 0.7.18 notes follow, for anyone updating from an earlier version.

## New in 0.7.19

- **Downloading a Project works again with a kept preview**: a Project with a Concordance, Quotation or Annotator preview that hadn't been run could fail to download with an internal server error. It now downloads, and the preview still works when you import the Project.
- **New files and Projects are easy to find**: after you upload files, import sample data or an LDaCA collection, or import a Project, the new file, folder or Project pulses with an outline and scrolls into view. The outline goes once you click it.
- **Topic Modelling says "passage" instead of "segment"**: the stretches of text Topic Modelling groups into topics are now called passages throughout the settings, results and help. The setting that chooses how text is split is now **Passages**. Nothing else changes: saved Projects, column names such as `TOPIC_segment_count`, and the Data Builder's **Segment** tool stay as they are.
- **Tasks stays tidy**: a successful import or upload now leaves the **Tasks** panel on its own 10 minutes after it finishes. Failed and cancelled ones stay until you clear them, so you don't miss an error. The new brush button beside the **Tasks** heading clears all finished imports and uploads at once. Finished imports are also cleared when you start the desktop app again, or when you sign out of a shared server. Your imported files are never removed.
- **Check for Updates always shows the newest version (desktop app)**: if the update window from an earlier check was still open, **Check for Updates** could offer an older version than the newest. It now checks again. This fix takes effect from the version after the one you install it with.

## What came in 0.7.18

- **The same topics every time**: running Topic Modelling again on the same text with the same settings and seed now gives exactly the same topics, on any computer or server. Before, a computer with several processors could give a slightly different set of topics on each run of a corpus with more than about 8,000 passages. Because of this fix, a run made with 0.7.18 can differ a little from the same run made with an earlier version.
- **The end of Topic Modelling is quick and light on large corpora**: the last step ("finding each topic's words") could spend many seconds on one processor and several gigabytes of memory preparing the results of a large corpus. It now takes a fraction of a second and a fraction of the memory. The topics and their sizes are unchanged.
- **The Search term example is lighter**: "e.g. house, pre, gov" in the Topic Modelling search box is now grey, like other examples, so it doesn't look like typed text.
- **A notice from the server you use (shared servers)**: a shared Wordflow server, such as Wordflow online, can now show a short notice at the top of the workspace, for example where your files and Projects are stored and who can access them. Choose **Got it** to hide it; it shows again if the text changes. Server operators: see `SERVER_NOTICE_FILE` in the hosted deployment runbook.
