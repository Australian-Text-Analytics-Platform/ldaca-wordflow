Wordflow 0.7.19 (not yet released; draft). The 0.7.18 notes will follow at release, for anyone updating from an earlier version.

## New in 0.7.19

- **Downloading a Project works again with a kept preview**: a Project with a Concordance, Quotation or Annotator preview that hadn't been run could fail to download with an internal server error. It now downloads, and the preview still works when you import the Project.
- **New files and Projects are easy to find**: after you upload files, import sample data or an LDaCA collection, or import a Project, the new file, folder or Project pulses with an outline and scrolls into view. The outline goes once you click it.
- **Topic Modelling says "passage" instead of "segment"**: the stretches of text Topic Modelling groups into topics are now called passages throughout the settings, results and help. The setting that chooses how text is split is now **Passages**. Nothing else changes: saved Projects, column names such as `TOPIC_segment_count`, and the Data Builder's **Segment** tool stay as they are.
- **Tasks stays tidy**: a successful import or upload now leaves the **Tasks** panel on its own 10 minutes after it finishes. Failed and cancelled ones stay until you clear them, so you don't miss an error. The new brush button beside the **Tasks** heading clears all finished imports and uploads at once. Finished imports are also cleared when you start the desktop app again, or when you sign out of a shared server. Your imported files are never removed.
- **Check for Updates always shows the newest version (desktop app)**: if the update window from an earlier check was still open, **Check for Updates** could offer an older version than the newest. It now checks again. This fix takes effect from the version after the one you install it with.
