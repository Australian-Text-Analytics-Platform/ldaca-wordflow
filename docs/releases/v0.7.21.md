Wordflow 0.7.21 adds two new ways of working: the **AI Code Designer** drafts a first Codebook for Annotation from a short brief and a sample of your texts, and a Data Block can now be dragged from the Project Graph or the sidebar onto a tool. In Topic Modelling, the words in a bubble's word cloud can be clicked to search for them or to hide them. Frequency's display settings take less room, so more of the word cloud fits on the first screen. Buttons and help icons say more clearly what they do, Help gains a Glossary and a Settings page, and chart image downloads work again.

## New in 0.7.21

### Annotation

- **AI Code Designer**: writing the first Codebook is the hardest step of AI annotation. In the **Edit codebook** window, write a **Brief** of up to 250 words saying what the coding is for, choose the **Maximum classes**, and choose **AI Code Designer**. Wordflow sends the brief and a sample of your texts (100 by default) to the AI provider you choose, and the model drafts the codes with their definitions, plus a code named Other. The designer works in Manual mode too, so you can use it to start a Codebook you will apply by hand.
- **The draft is yours to check**: the designer is a starting point, not a finished Codebook. Review every code before you use it, including for real text or names from your data, which the model is asked to leave out but may not. The draft is not saved until you choose **Save**. A model that reasons well gives better codes; **Thinking effort** starts on High, and the window shows progress while it works, because such models can take minutes.
- **Unsaved Codebook changes are kept**: codes you type or draft now stay when the Edit codebook window closes, and the Codes card shows **Draft, not saved** until you save or discard them. **Cancel** asks before discarding. Reloading Wordflow still loses unsaved codes.

### Adding Data Blocks to a tool

- **Drag a Data Block onto a tool**: drag a Data Block from the Project Graph, or from the **Data Blocks** list in the sidebar, onto a tool's Data Blocks box. A label follows the pointer and says where the Data Block will go, and the Data Blocks boxes are highlighted while you drag. The Data Block is added after the ones already there, as **Add Data Block** does. A box that is full says so.
- **The Project Graph moves only from its background**: dragging a Data Block no longer moves the whole graph. Drag the empty background to move it. Clicking and double-clicking a Data Block work as before.

### Topic Modelling

- **Click words in a bubble's word cloud**: the word cloud that appears over a bubble now stays while your pointer is in it. Click a word to add it to the **Search term**; click it again to remove it. Right-click a word to add it to the stop words. The cloud appears after the pointer rests on a bubble for a moment, so moving across the chart no longer covers the bubble you are aiming at, and holding Shift keeps the cloud open.
- **The search filters when you ask**: matches are coloured as you type or click, but the bubbles and the Topic list are filtered only when you choose **Apply** or press Enter, so the chart stays still while you put a search together. Emptying the box shows every topic again. Each search term keeps its colour while you add others.
- **See which words are hidden**: under the stop words control, **Hidden words** names the first eight stop words in use, newest first, and counts the rest. The stop words editing window has **Sort**.

### Frequency

- **More room for the word cloud**: the settings above the cloud took so much space that on a small screen the cloud started below the first screen. Stop words now take one row, and the list opens with **Edit list** and closes with **Hide list**. While it is closed, a line names the first eight hidden words. **Filter tokens**, the display limit and the **Cloud view / List view** selector share one row, showing the limit for the view on screen. The **Apply** buttons are gone: a limit applies when you press Enter or leave the box.
- **The cloud shows 40 tokens by default**: it was 25, and the Help said 50. Results you already have keep their limit until you run again or change it.

### Clearer buttons and help

- **Each Clear button says what it clears**: three different buttons were all called **Clear**. They are now **Clear results** (removes the tab's results), **Remove all** (takes every Data Block out of the tool) and **Clear filter** (empties Frequency's token filter). They do what they did before.
- **Add to Project says what you will get**: the window now opens with what one row of the new Data Block will be, for example "Each match becomes one row in the new Data Block", and that the Result and the original Data Block stay as they are.
- **One help icon for Preview, Run and Clear results**: every analysis tool now has one **?** at the end of that row, opening the tool's Run step in Help. Topic Modelling and Annotation had none before.
- **Concordance's context inputs have names**: screen readers now announce **Left context (tokens)** and **Right context (tokens)**.

### Help and Settings

- **A Glossary**: Help has a new **Glossary** page for the words Wordflow has made its own, such as Data Block and passage, and for the technical terms of text analysis, such as token, tokeniser and log-likelihood. Each entry is a sentence or two with a link to the full explanation. It says, for example, the three ways a Data Block comes about, and how the Plain words tokeniser splits text: "high-school" becomes "high" and "school", and "don't" becomes "don" and "t".
- **A Help page for Settings**: Help has a new **Settings** page that says what each setting does and where it is kept (with your account, on this computer or in this web browser). A **?** beside each group of settings opens its section.
- **When hints and suggestions appear**: the page has a section on Wordflow's two kinds of guidance. **Contextual Hints** teach the interface as you reach each step for the first time; **Suggestions** appear when a result or a run looks off. A table lists every situation that shows a Suggestion and what it suggests, and the section says how to turn each kind off and on.
- **Bringing hints back**: a hint you have acknowledged does not appear again. The new **?** beside **Reset Contextual Hint history**, under **Settings → Guidance**, explains that this button lets those hints appear again.
- **The Account badge is gone**: the badge at the top right of Settings looked like a button but did nothing.

## Fixed

- **Chart image downloads show the chart**: since 0.7.11, downloading a Trends chart on a date or number column as PNG, JPEG or SVG gave a thin strip with a "?" icon in place of the chart. Downloads now show the chart, with its grid lines and range slider, in the light and dark themes. Concordance's dispersion chart downloads keep their grid lines too.

## Good to know

- This release includes security updates to the libraries Wordflow is built on, in the desktop app, the server and the Binder environment.
- The AI Code Designer sends your brief and a sample of your texts to the AI provider you choose, as Annotation in AI mode does. Use it only with texts you may share with that provider.
- Server operators: no settings change.
