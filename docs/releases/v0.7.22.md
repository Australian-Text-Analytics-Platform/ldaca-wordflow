Wordflow 0.7.22 opens JSON files that are not tables: you choose where a file's rows are, and a folder of JSON files can become one Data Block. Annotation gains ordered-scale codebooks, such as levels from low to high, with reliability scores that count how far apart two codes are, and it checks the annotation column before a Run writes to it. Every list of columns now shows each column's data type with the Data Editor's symbol, and the group pickers in Trends and the Data Builder offer only columns that can be grouped. Quotation and the Chinese and Japanese tokenisers work again on Windows computers where they failed, and this release fixes several cases where values or names could be changed or lost.

## New in 0.7.22

### Loading JSON files

- **Choose where a JSON file's rows are**: a JSON file need not be a table. The file preview and the Add window have a **Rows from** menu that lists every place in the file holding records, with the place holding the most text first. For an OCR tool's output, for example, that is its text blocks rather than its detection boxes. Each record becomes a row of its own fields; values nested deeper are kept as JSON text, and a field that mixes kinds of values becomes text instead of failing.
- **JSON files as one Data Block**: a folder, a selection or a ZIP with JSON files can add them as one Data Block, every file read the same way, with a `file_path` column that names the file each row came from. A record's own field of that name is kept as `file_path (record)`. Files that can't be read are left out and listed in a window, which Tables mode now shows too.
- **The file preview keeps its headings in view**: the heading row stays at the top while the rows scroll, and each column's resize divider is a visible line.

### Annotation

- **Ordered-scale codebooks**: a codebook can be an ordered scale, with levels from the lowest to the highest, and codes outside the scale, such as Not applicable, listed below it. The AI Code Designer can draft one, and AI annotation rates each text against the level definitions. **Compare to** then uses weighted Kappa and ordinal Alpha, which count a near miss as closer than a far one. With Alpha and two or more comparisons, the annotation column also shows Alpha across all coders.
- **A Run checks the annotation column first**: a line under the AI setup says what the chosen column already holds. If it holds codes, Run asks whether to fill only the empty rows or replace every code. If it holds values that are not codes, Run warns that the column or the codebook may be wrong and asks before overwriting the whole column.
- **The Manual table follows the codebook**: choosing another codebook while the Manual table is open now updates the table at once, keeping its page, filters and Compare to columns. Score tooltips say which columns are left out because they hold no codes of the selected codebook, and hovering a grey italic value explains it.
- **Long texts fit the model**: Runs and Previews fill each request with as many texts as fit the model's context window, so long texts no longer make requests the model must refuse. A text too long on its own fails only its own row, and the message names the model and its limit.
- **Download a reliability score as an image**: each score's popup has a **Download** icon that saves the score, its method and coders, any codebook note, and the comparison table with its key, as SVG, PNG or JPEG.
- **Edit codebook fits the window**: on a laptop the window ran off the screen. It now stays within the window with its buttons in view. The brief and the codebook sit in two panes with a bar between them to drag, and the AI Code Designer window stays within the screen too.
- **The AI Code Designer in any language**: the catch-all code takes the brief's language, so 其他 is no longer doubled by an English Other. Chinese and Japanese are counted by characters, and a Brief in those languages can be up to 500 characters.
- **Tooltips on the table toolbars**: Compare to, Correction, Use as example, Show metadata and Download each say what they do, and one help icon ends each Annotation table's toolbar.

### Column lists and grouping

- **Each column's type at a glance**: wherever you choose columns, each name follows the symbol the Data Editor shows in its column headers, such as **Aa** for text, **123** for a whole number or a calendar for a date. This covers the column pickers of every tool, the **Show metadata**, **Compare to**, Deduplicate and **Delete columns** lists, the **Add to Project** and download windows of results, and Aggregate's list. Point to a symbol to see the type's name.
- **Trends: Add group offers columns with up to 16 different values**: more lines than that cannot be told apart in the chart. Each column shows its number of values, and a line says so when no column fits. A group column chosen in an earlier version that has more values is marked in red, and Run waits until you choose another.
- **Data Builder Group lists only columns that can be grouped**: under **Split by**, a text, category or true/false column is listed only when it has 50 or fewer different values, because each value becomes a Data Block, and it shows that number. Number, date and elapsed time columns are always listed, because they are grouped into ranges or periods. A **?** beside **Split by** gives the rule.

### Concordance and Quotation Previews

- **Download and Add to Project stay in view on a Preview**: they used to appear only after Run, so they seemed to be missing. They now stay in place, unavailable, and hovering them says a full Run comes first.
- **Previews say so**: while Preview Results are showing, each Data Block's title ends in (Preview), and so do the dispersion chart's title and a downloaded chart's title and file name, so a chart of a few documents is not later read as the whole Data Block.
- **Clearer footer**: the footer under a Preview now reads "Choose Run to check all N documents."

### Around the app

- **A reminder that Advanced holds more settings**: while **Advanced** is off, a short light blue line beside the switch says that turning it on shows more settings and their defaults. **Got it** hides it for that tool until the next update.
- **Step through rows with the arrow keys**: Left and Right step to the previous and next row, passage or item in Row Details and in the Concordance, Quotation, Annotation and Topic Modelling viewers.
- **Export from the sidebar**: a Data Block's menu in the sidebar has **Export**, which opens the same window as the Project Graph's.
- **Data Builder tabs say what each tool does** when you point to them. **Sample** opens on **Random sample**, and **Slice** is now called **Row range**.
- **Trends: Minimum group count says what it does**: its tooltip names the number in the box, for example "Groups with fewer than 10 rows are hidden from the chart. Enter 1 to show every group."
- **The app is named Wordflow (by LDaCA)** in its windows, the browser tab, the desktop app and the help. Installed desktop apps update as before.

## Fixed

- **Quotation and the Chinese and Japanese tokenisers on Windows**: on some Windows computers Quotation failed with only "BrokenProcessPool" under Details, and the tokenisers for Chinese and Japanese did not work. The models Wordflow downloads are now kept in your data folder, and a failure's Details name its real cause.
- **Converting text to a whole number keeps long identifiers apart**: text was read as a decimal number first, so `9007199254740992` and `9007199254740993` became the same number, and a later join or duplicate check could match unrelated rows. Digits are now read exactly as written.
- **Trends number groups**: with a Start of 1.2 and a Step of 0.1, the value 1.4 was counted in the group `[1.3, 1.4)`. Values on a group's edge now go in the group they start. Group labels keep every digit, so a very small step no longer gives every group the start 0.
- **Concordance Whole word with terms such as C++ or #reef**: `C++` was found in "C++17" but not in "I write C++ today." A term that starts or ends with punctuation is now found where no letter or digit touches it.
- **Bundled export file names**: Data Blocks named `notes`, `notes` and `notes_2` gave two files called `notes_2` inside the ZIP, and unzipping kept only one. Every file now gets its own name.
- **Deduplicate keeps every column**: near-duplicate matching dropped a column called `__dedupe_text`.
- **Chart settings in a narrow pane**: the options above a chart, such as Trends' **Chart**, **Spacing** and **Show as**, slid off the left edge out of reach. They now wrap onto further lines.
- **AI providers set up on a server**: the AI Code Designer failed with every provider the server set up, and Annotation Runs failed with providers that label requests with the person's name. Both work now.

## Good to know

- The models Wordflow downloads (for Quotation, the tokenisers, Topic Modelling and Chinese and Japanese) now live in your data folder. On first start, the models an earlier version downloaded come into it once. If you choose another data folder, they download again when needed.
- Server operators: no settings change.
