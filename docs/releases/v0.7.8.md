Wordflow 0.7.8 fixes the problems found in 0.7.7, adds new Data Editor and Data Builder tools, and rewrites messages, labels and help in plain words.

## New tools

- **Data Editor column tools**, with a live preview in the table: Find & replace, Extract text, Combine columns, Copy column, Clean text (including Remove XML tags and markup), Split column, and Count (words, characters or matches). Tools stay open after Apply, so you can make several edits in a row.
- **Data Builder**: new Segment, Group, Aggregate and Deduplicate tools.
- **Data types**: a Date type; changing a type reports every value it couldn't convert, with Undo.
- **Data Loader**: add a folder of texts as one Data Block; add a folder or ZIP as texts or as separate tables; move, multi-select and batch-delete files; download a selection as one ZIP.
- **Export**: Excel (.xlsx), and CSV that opens correctly in Excel.

## Analysis tools

- **Frequency and Keyword Analysis**: keyness measures the Study corpus against the Reference corpus; frequency per million words; plain explanations and a significance legend.
- **Concordance**: dispersion markers line up with the selected range; Whole word works on Japanese and Chinese text; Tokens mode explained plainly.
- **Trends**: Normalise to 100% shows each group as a share of its period; new Stacked bars chart type; side-by-side bars have alternating period backgrounds; one readable date format on every chart; lines no longer vanish in Safari.
- **Topic Modelling**: paragraph-first segmentation, Max topic size, colour bubbles by a metadata column, and add rows per topic to the Project.
- **Quotation**: explanations of the quote types; Row Details opens at the quote.
- **Annotation**: see the whole row while annotating.

## Everywhere

- Messages, labels and help in plain words, with technical details kept under **Details**. "Workspace" is now **Project**.
- Tables keep their scroll position; analysis tabs are named F-1, C-1, T-1, TM-1, Q-1 and A-1; the active tab stays in view.
- A plain scroll over a chart scrolls the page; hold Cmd (Ctrl on Windows) to zoom. Click and Shift-click select periods.
- Visible resize handles, and a readable macOS title bar over light desktops.

## Upgrading

Projects saved by 0.7.8 can show Topic Modelling tabs as unavailable if you open them in 0.7.7. Nothing is lost: open them in 0.7.8.
