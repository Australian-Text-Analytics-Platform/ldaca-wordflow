# Current application tour

The left sidebar contains Tools, Data Blocks and the Task Centre. Data Loader,
Preprocessing and Frequency are available; other analysis tools remain disabled.

The center displays the active tool. The right column contains Project Graph
and independently opened data previews. Selecting a graph card and opening its
preview are separate actions; use its **Preview data** button to inspect rows.

Use the native File menu for project files and **Settings** for appearance and
updates. **Help** opens the bundled guide inside the application.

The [UI tutorial](../../public/tutorials/ui.md) is the canonical detailed guide.
See [Data Loader](../../public/tutorials/data-loader.md) for imports and
[preprocessing](../../public/tutorials/preprocessing.md) for DuckDB operations
and the persistent SQL console.
