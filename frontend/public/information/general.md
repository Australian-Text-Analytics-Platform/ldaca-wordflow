<h1 id="info-general-overview">About Wordflow</h1>

Wordflow **8.0.0** is a native application for exploring and analysing text
collections on desktop and the server. Import files, sample datasets or LDaCA
collections, prepare them with visual tools or DuckDB SQL, and analyse them with
Frequency, Concordance, Topics, Quotation, Annotation and Plots.

Your work is organised into **projects**, saved as `.wfpj` database files. Each
project keeps its Data Blocks, SQL definitions and saved analysis outputs together.
Data Builder creates derived Data Blocks and Data Editor changes columns in place.
New Topics, Concordance and Quotation outputs attach to current source rows by
exact text; metadata edits update their presentation without refitting outputs.
Add to Project creates an independent live View with owned generated outputs.
Annotation writes labels directly to its source Table.

No programming or command-line knowledge is required. The platform is designed for researchers across all disciplines.
