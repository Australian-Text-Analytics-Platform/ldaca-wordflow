<h2 id="info-preprocessing-overview">About Data Builder</h2>

The Data Builder makes new Data Blocks from existing ones, ready for analysis. Filter, Sample, Join, and Stack always create a new Derived Data Block and never change their sources. To add or change columns on a Data Block in place (find and replace, combine, duplicate, split, or clean text), use the Data Editor below the Project Graph.
