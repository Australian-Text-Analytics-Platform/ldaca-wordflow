<h2 id="info-preprocessing-overview">About Data Builder</h2>

The Data Builder makes new Data Blocks from existing ones, ready for analysis. Its tools are Filter, Group, Join, Segment, Aggregate, Sample, Deduplicate, and Stack. Each one creates new Derived Data Blocks and never changes its sources. To add or change columns on a Data Block in place (combine, count, duplicate, extract, split, find and replace, or clean text), use the Data Editor below the Project Graph.
