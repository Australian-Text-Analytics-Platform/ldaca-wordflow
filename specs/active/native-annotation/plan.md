# Implementation sequence

1. Shared table protection, typed row references, mutation preconditions and
   transactional reference reconciliation.
2. Manual Annotation, Codebook patches, live draft-aware comparisons and
   Save/Discard/Stay navigation.
3. Host provider configuration, OS credentials and concrete HTTP adapters.
4. Fresh Preview and full-data Run, atomic labels and saved report/context.
5. Archived parity, performance, browser/native/release QA and canonical docs.

Each stage must retain existing lifecycle ownership, cancellation and single
notification authority. Verify changes against focused tests before broadening.
