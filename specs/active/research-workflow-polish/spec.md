# Research workflow polish

Implement the approved research-review improvements without a project schema change:
complete-only stopword selection, calendar-safe Arrow dates, duplicate-preserving
Stack defaults, readable chart containment and figures, synchronized Calendar
inspection, Topic document inspection, clearer context/export/recent-file displays,
and per-run native E2E browser storage.

Preserve saved analysis ownership, lazy source execution, all observations and
publication semantics. Do not add counting scans, graph-layout changes, quotation
model changes, or persistent Preview storage.

Canonical behavior is documented in the [frontend architecture](../../../docs/architecture/frontend/overview.md),
[API reference](../../../docs/reference/native-project-api.md), and
[desktop architecture](../../../docs/architecture/frontend/desktop.md).
