- Browser: both Concordance scenarios passed, including actual point/range
  gestures, preview persistence, publication and source-independent reopening.
- Native: both scenarios passed in the actual Tauri WebView. Inspected light and
  dark screenshots at normal and narrow pane widths separately from Chrome.
- Native driver does not map Home/End (verified in its key mapping); native
  gestures use supported arrows, and component tests cover Home/End explicitly.
- Native error captures contain only the existing injected-driver stale-element
  signals with root-only stacks; the existing diagnostic policy distinguishes
  these from application errors. Browser application error capture is empty.

  from KWIC matches never temporarily renders those rows as duplicate documents.

  selection uses the completed brush's percentage-axis range across all modes.
- The initial unrestricted frontend test run hit two preprocessing timeouts
  while Rust builds competed for CPU. The full suite passed with two workers.

  tooling type checks, documentation drift/links and diff checks passed.

- Browser downloads: real SVG, PNG and JPEG files verified, including chart paths,
  source/query/scope/legend labels and PNG/JPEG signatures. Visually inspected PNG.

  cancellation, rollback, task identity and destination installation. The OS save
  chooser was not manually exercised in this restoration.
