# Strengthen realistic E2E coverage

Replace weak completion checks with independently calculated data assertions and
real user transitions. Preserve small exact-answer regressions and the strict
unexpected-session-error gate. The scope is testing, fixtures and CI; no new
application features or test-only application API are required.

Acceptance covers all plot modes' selected-row publication, Annotation's staged
and committed effects plus provider failure/cancellation, complete export values
and genuine project-runtime reopening, more varied Topic Modelling text and both
published inputs, imported-file preprocessing across tools, and saved-request
compatibility in every analysis kind. Browser and actual native evidence are
reported separately. External-service and OS integration acceptance remain
explicitly distinct from deterministic application E2E.
