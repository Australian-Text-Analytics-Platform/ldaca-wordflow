# Nested Build expressions

Build creates or replaces one column through a recursive bubble tree or an
editable DuckDB expression. Restore the searchable column palette, copy/move
interactions, nested function containers, operation chips and typed values.
SQL-to-GUI conversion uses DuckDB's parser; unsupported fragments remain SQL
bubbles. Summary execution form remains fixed across destination changes.

Preserve shadcn/VS Code styling, destinations, View Undo, transactional Table
updates, concurrent Apply, independent previews and format 6. Add only the
read-only expression parsing endpoint, with no dependency or draft persistence.

Canonical behavior: [preprocessing architecture](../../../docs/architecture/frontend/preprocessing.md),
[API](../../../docs/reference/native-project-api.md#expression-parsing),
and [Build tutorial](../../../frontend/public/tutorials/preprocessing.md#help-preprocessing-build-section).
