# Native Concordance restoration

Restore the archived Concordance workflow in named Request/Results tabs, with
explicit temporary Preview and one latest successful Run All result per tab.
The user-approved scope includes native Text/token matching, metadata, table and
dispersion presentations, document inspection, atomic Add to Project, chart
downloads and Frequency token navigation.

Preview reads a requested source-document page plus lookahead for pagination,
matches only the requested page, never stores an artifact, and is cancelled with its request. Saved results retain
matching original rows and separate occurrences in private format-7 relations.
Source edits/deletion cannot alter those saved rows.

Use the existing task, editor, query-invalidation, preference and export ownership.
No format migration, worker process, task tree, persistent Preview, result history
or other analysis tool is introduced.

Canonical contracts belong in the native analysis architecture, API reference,
frontend architecture and user tutorials, rather than being duplicated here.
