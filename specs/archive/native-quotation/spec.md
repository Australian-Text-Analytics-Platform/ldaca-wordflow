# Native Quotation restoration

Restore the built-in English Quotation extractor in named Request/Results tabs.
Use explicit request-scoped Preview, page source documents with lookahead, and
retain one successful Run All result per tab. Each source document can yield zero
or multiple quotes. Preserve typed original rows independently of live sources.

Restore source/column selection, source color, Preview/Run All/Stop/Clear,
Preview/Saved results, document/match paging, metadata, sortable saved fields,
word-context clipping, quote/speaker/verb highlights, full-document inspection,
and independent Data Block publication. Use the native UDPipe implementation and
pinned model. This restoration covers the built-in engine; archived operator-configured remote
providers remain unavailable.

Share typed document capture/Arrow enrichment and existing result/task ownership
with Concordance. No worker process, persisted Preview, task tree or format change.
