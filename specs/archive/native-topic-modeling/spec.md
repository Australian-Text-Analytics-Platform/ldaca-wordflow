# Native Topic Modelling

Restore the archived Topic Modelling workflow using the current Tab → Analysis →
Artifacts ownership, without changing project schema version 1. One or two Data
Blocks fit one joint model. Run processes every row; Preview fits a seeded sample
chosen in a dialog and retains its model only while its response connection lives.

The shared representative-word tokenizer appears in both input cards. Embedding
tokenization is separate. Defaults are English MiniLM, Automatic segmentation,
256 tokens, minimum topic size 10 and seed 0. Sampling defaults to 1,000 documents
per input, with percentage sampling available. Sampling settings are local only.

The approved output preserves topic merging, positive Top-N memberships with
cutoff ties, complete character coverage including outlier -1, representative
word filtering, search, lasso, selection, hover clouds and map navigation. Bubble
area represents membership and map scaling is uniform. Word projection cannot
recalculate map coordinates. Downloads include sampled/full-data scope.

Only saved results publish original annotated rows and a complete topic dictionary.
Published objects remain independent. No selected topics means all retained rows;
selected topics use the union of positive Top-N memberships. Zero-topic output is
valid and publishable. Preview cannot publish.

The full user-approved plan in the implementation conversation is the acceptance
scope. The [task checklist](tasks.md) records verification, including unverified
gates; the archived source remains unchanged.
